# Data Science & Modeling

Welcome to the **Data Science & Modeling (DSM)** course materials. This book is designed to take you from the basics of Python programming through the intricacies of inferential statistics and machine learning.

## At a Glance

This resource is divided into five main sections:

* **Part I: Fundamentals** – Setting up your environment and mastering Python syntax.
* **Part II: Working with Data** – Deep dives into `NumPy` and `Pandas`.
* **Part III: Visualization** – Learning to tell stories with data using `Matplotlib` and `Seaborn`.
* **Part IV: Inferential Statistics** – Understanding probability, hypothesis testing, and regression.
* **Part V: Machine Learning** – Applying models for classification and clustering.

## How to Use This Book

Each chapter is an interactive Jupyter Notebook. You can read through the rendered content here, or interact with the code directly if you have the environment set up locally.

> **Note:** If you are new to the course, please start with the [Preface](chapters/preface) and the [Appendices](chapters/appendices/0200-intro-jupyter) to ensure your local environment is configured correctly.
