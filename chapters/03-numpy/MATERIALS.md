# Chapter 03 Materials

## Purpose

Chapter 03 introduces NumPy arrays as the foundation for efficient numerical work in Python. It prepares students to represent business data as arrays, compute with whole collections, and use simulation as a management decision tool.

## Source Notebooks

- `0300-intro-np.ipynb` - chapter landing page for NumPy arrays.
- `0301-np-basics.ipynb` - array creation, shape, indexing, slicing, and basic array operations.
- `0302-np-ufuncs.ipynb` - vectorized computation and universal functions.
- `0303-np-random.ipynb` - random number generation and simulation.
