# Chapter 03 Organization

## Chapter Role

Chapter 03 bridges basic Python and table-oriented data work by teaching students how NumPy represents and computes over numerical collections.

## Learning Goals

Students should be able to:

1. Create NumPy arrays from simple Python data.
2. Inspect array shape, size, and data type.
3. Select array values with indexing and slicing.
4. Apply vectorized operations and universal functions.
5. Use random number generation to model uncertainty in business settings.
