# Python Basics

This chapter introduces three fundamental areas of Python you'll use immediately: 
1. variables, 
2. operators,  
3. Python built-in data types
4. the print() function.

Python is a core tool in data science because it is easy to learn, reflecting its origins as a scripting language with a flexible, loosely typed approach. That low barrier to entry is paired with a rich ecosystem of libraries for data wrangling, visualization, and machine learning. Packages like pandas, NumPy, and scikit-learn let you move quickly from raw data to analysis and models.
