# Chapter 05 Organization

## Chapter Role

Chapter 05 gives students a first practical framework for choosing and reading charts before the dedicated Matplotlib and Seaborn chapters.

## Learning Goals

Students should be able to:

1. Explain how visualization supports exploratory analysis and management communication.
2. Choose basic chart types for common business questions.
3. Create simple plots from pandas objects.
4. Interpret chart patterns, outliers, and comparisons carefully.
5. Identify when a visualization may mislead an audience.

## Sequence

1. `0500-visualization.ipynb` - Visualization
   - Chapter orientation
   - Learning goals
   - Chapter flow
2. `0501-pandas-vis.ipynb` - Pandas Plotting Basics
   - Plotting from pandas
   - The `.plot()` method
   - Plotting method variants
3. `0502-pandas-chart-types.ipynb` - Pandas Chart Types
   - Choosing chart types
   - Reading patterns in business data
   - Line, histogram, scatter, bar, box, area, KDE, and hexbin plots
4. `0503-pandas-plot-styling.ipynb` - Pandas Plot Styling
   - Plotting styles
   - Color maps
   - Marker size and visual emphasis
5. `assignments/index.ipynb` - Assignments
   - Preview
   - Lab
   - Homework
